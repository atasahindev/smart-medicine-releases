# Akıllı İlaç — Masaüstü Uygulaması

Akıllı İlaç, ilaç saatlerinizi takip etmenizi, hatırlatmalar almanızı ve yakınlarınızın ilaç durumunu görüntülemenizi sağlayan ücretsiz bir Windows masaüstü uygulamasıdır.

**Tüm sürümler:** [Releases](https://github.com/atasahindev/smart-medicine-releases/releases)

## Sistem Gereksinimleri

- Windows 10 veya üzeri (64-bit)
- En az 200 MB boş disk alanı
- İnternet bağlantısı gerekmez (uygulama tamamen yerel çalışır)
- .NET ayrıca kurulmaz — kurulum paketinin içinde gelir

## Kurulum

1. Yukarıdaki **Akilli-Ilac-Setup-1.0.1.exe** dosyasını indirin.
2. İndirilen dosyaya çift tıklayın.
3. Kurulum dizinini seçin (varsayılanı kullanabilirsiniz).
4. Kurulum tamamlandığında masaüstü veya Başlat menüsünden **Akıllı İlaç**’ı açın.

> Windows SmartScreen uyarısı görürseniz: Uygulama henüz kod imzalı değildir. **Diğer bilgiler** → **Yine de çalıştır** ile devam edebilirsiniz.

## Özellikler

- İlaç ekleme ve günlük doz takibi
- Zamanında hatırlatmalar ve erteleme
- Takvim görünümü
- Yakın takibi ve bildirimler
- Türkçe arayüz
